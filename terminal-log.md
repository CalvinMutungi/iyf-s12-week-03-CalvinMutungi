# Terminal Command Log

| Command | Description / Purpose |
| :--- | :--- |
| `pwd` | Displays the current working directory path. |
| `ls -la` | Lists all files and directories, including hidden ones (`.gitignore`), with details. |
| `mkdir` | Creates a new directory. |
| `git status` | Displays the working directory and staging area state. |
| `git add .` | Stages changes in the directory for commit. |
| `git commit -m "..."` | Records staged changes to the local repository history with a message. |
| `git checkout -b <branch>` | Creates and switches to a new feature branch. |
| `git merge <branch>` | Merges changes from a feature branch into the target branch. |
